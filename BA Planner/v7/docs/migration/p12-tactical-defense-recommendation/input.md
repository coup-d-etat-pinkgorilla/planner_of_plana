# P12 예상 방어덱과 설명 가능한 추천 입력

## 선행 기준

- P9의 공개/완전 snapshot, 상대 identity와 match link
- P10의 공격덱 관측 결과와 Wilson 구간
- P11의 `as_of`, 시간 감쇠, 변경 이후 검증과 관측/예측 분리

## 구현 목표

- 같은 상대·공개 signature·시즌에서 전체 공개 signature까지 6단계 근거 탐색
- 실제 관측된 완전 방어덱만 TOP-K 시나리오로 반환
- 좁은 단계 표본이 부족할 때 명시적인 더 넓은 단계 근거로만 보정
- 숨은 슬롯별 관측 후보, 공개 signature 모호성과 변형 가능성
- 같은 상대·완전 방어·공개 signature 근거를 분리한 공격덱 추천
- 보유 학생 적용 가능 여부와 점수의 결과·최근성·표본·상대·출처 구성
- 시간 순서 holdout의 TOP-1/TOP-K/숨은 슬롯/Brier/log loss 검증

## 안전 경계

- 예측을 관측 snapshot으로 저장하지 않는다.
- 관측되지 않은 슬롯 독립 조합을 새 완전 덱으로 생성하지 않는다.
- 근거가 없으면 빈 시나리오/추천과 구조화된 unavailable reason을 반환한다.
- calibration gate 전에는 정밀 확률 대신 신뢰 등급을 기본 표현으로 반환한다.
