# S5 실제 클라이언트 육안 검증

`release/ba_planner_v7.exe`를 실행하고 실제 Blue Archive 클라이언트를 대상으로 학생 스캔을
수행한다. 다음 항목을 확인하고 빨간 상태와 녹색 상태의 스크린샷을 보존한다.

1. 문제 후보는 빨간 테두리이며 `수정`, `재검증`, `보류`가 보이고 `적용`은 보이지 않는다.
2. 수정 후 재검증이 성공하면 녹색 테두리와 `적용`이 나타난다.
3. `적용` 후 확정 현재값과 repository revision이 갱신되고 후보가 중복 적용되지 않는다.
4. `상세 증거`에서 보유한 다른 의상의 portrait, 확인 인연 랭크, ownership, flat/coefficient/
   base modifier가 누락되거나 잘리지 않는다.
5. 호시노 계열을 사용할 경우 확인값 29/37/24가 각 의상에 대응하고 모든 보유 의상 기여가
   계산에 포함된다.
6. 패시브 스킬과 전용무기 패시브가 적용되는 학생은 계산 스탯과 실제 클라이언트 표시값이
   일치한다. 불일치 시 학생/의상, 스킬 레벨, 전용무기 성급과 표시 스탯을 기록한다.
7. 좁은 창, 일반 창, 최대화 상태에서 결과 목록·상세·버튼이 겹치거나 잘리지 않고 스크롤로
   접근 가능하다.

승인 시 스크린샷 경로 또는 관찰 결과를 `output.md`에 추가하고 S4 snapshot과 S5를 최종
승인한다. 문제가 있으면 상태, 창 크기, 학생/의상과 재현 순서를 함께 기록한다.
